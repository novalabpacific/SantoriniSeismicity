# Santorini–Amorgos Seismicity Analysis

Reproducible Python code, data, and figures for analyzing the spatial patterns and temporal evolution of seismicity during the 2025 Santorini–Amorgos seismic unrest.

## Overview

This repository provides a cross-catalog comparison of earthquake locations and seismicity patterns, including spatial orientation, temporal evolution, and statistical analyses.

## Repository Contents

- `data/` – Earthquake catalog data
- `maps/` – Geographic data used for visualization
- `figures/` – Figures generated for the analysis
- `analysis_stats.py` – Statistical analysis functions
- `analysis_pipeline.py` – Main analysis workflow
- `requirements.txt` – Python dependencies

## Usage

Install the required dependencies:

```bash
pip install -r requirements.txt
```

Run the main analysis:

```bash
python analysis_pipeline.py
```

The repository includes analysis scripts, input datasets, and numerical outputs to support reproducibility. See `DATA_SOURCES.md` for data provenance and attribution.
